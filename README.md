Django example for SF

Перед началом работа обязательно почитайте официальный [туториал](https://docs.djangoproject.com/en/5.2/intro/tutorial01/). Правда, там акцент на полноценное приложение, включая фронтенд.

## Бизнес логика проекта
- сущности: продукт, очередь;
- действия с продуктом:
  - создание;
  - обновление;
  - получение информации;
  - удаление;
- действия с очередью:
  - создание (с подвязкой к продукту / без него);
  - обновление (с возможностью подвязки к продукту);
  - получение информации;
  - удаление.

## Краткое описание Django
Django — высокопроизводительный веб-фреймворк с открытым исходным кодом, написанный на Python. Используется для быстрой разработки мощных и масштабируемых веб-приложений.

Главные достоинства:
- ORM (Object Relational Mapping), позволяющий удобно взаимодействовать с базами данных через объекты;
- MVC/MVT архитектура, обеспечивающая четкое разделение логики приложения от представления;
- высокая безопасность благодаря встроенным механизмам защиты от распространенных уязвимостей (XSS, CSRF);
- большое количество готовых модулей и библиотек, ускоряющих разработку приложений.

Подходит для быстрого прототипирования и создания крупных проектов корпоративного уровня. Часто используется для построения CRUD-систем, API-сервисов, социальных сетей, контент-менеджеров и сложных бизнес-приложений.
